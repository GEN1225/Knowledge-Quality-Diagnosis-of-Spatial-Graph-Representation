## 核心问题回答

### 1. 修复 scaler 泄露后，EGSG-250m 是否仍显著优于 Geo kNN？

**是**。

- R² 均值差: +0.0480
- Paired t-test p=0.000001
- Cohen's d=+3.9733

### 2. EGSG-250m 是否仍显著优于 RF？

**是**。

- R² 均值差: +0.0456
- Paired t-test p=0.000003
- Cohen's d=+3.2009

### 3. 修复 early stopping 后，R² 是否明显变化？

| Method | Pre-clean R² | Clean R² | Difference |
|--------|-------------|----------|------------|
| RF | 0.3889 | 0.3641 | -0.0248 |
| MLP | 0.3823 | 0.3787 | -0.0036 |
| Geo_kNN | 0.3430 | 0.3617 | +0.0187 |
| EGSG_250m | 0.4034 | 0.4097 | +0.0063 |

### 4. 当前最终可引用的 R²/RMSE/MAE

**EGSG-250m (clean protocol, 10 seeds)**:
- R² = 0.4097 ± 0.0230
- RMSE = 0.7675 ± 0.0143
- MAE = 0.5883 ± 0.0092
- Best epoch = 297 ± 5

### 5. 当前能否正式封存 EGSG-250m 方向？

**可以正式封存**。

Clean protocol 下 EGSG-250m 仍然显著优于 Geo kNN，实验协议无数据泄露，结果可作为论文引用数值。

## 关于 struct 边的说明

struct 边由于样本量较小 (605 样本) 且与全量样本 (7728 样本) 不在同一数据集上，不作为当前阶段主结论。当前封存结论只围绕 EGSG-250m、Geo_kNN、RF、MLP 四种方法。
