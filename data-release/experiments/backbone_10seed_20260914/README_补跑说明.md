## 三、GAT / APPNP 为什么对不齐（唯一残留差异）

GCN 与 GraphSAGE 逐位命中，而 GAT / APPNP 有 0.001–0.014 的偏移——这个组合本身就定位了原因：

- `GCNConv`、`SAGEConv` 是**实现稳定**的算子 → 命中。
- `GATConv`（注意力参数初始化 + 注意力 dropout）与 `APPNP`（传播 dropout）在
  torch_geometric 版本间**行为有变** → 偏移。
- 佐证：APPNP 的偏移**在 Geo 臂（不含 EGSG、图完全不经过剪边）上同样存在**
  （0.3738 → 0.3625），说明漂移发生在 APPNP 模块本身，而**不是**图构造环节。

因此这是**同一份数据的跨版本重跑差异，不是种子数问题**。
定性结论完全一致：GAT 上 ΔR² 草稿 +0.058 / 补跑 +0.057（均极显著），
APPNP 草稿 +0.029 / 补跑 +0.027（均极显著），GraphSAGE 两版都不显著。
